# Unity comparison import kit — NOT EXECUTED HERE

Unity Editor/Hub and an activated Editor licence are absent from this workspace.
No Unity import, compilation, playable runtime, APK, timing or device-performance
result is claimed. This is an executable-source candidate for operator testing,
not evidence that Unity has passed the comparison.

On an operator-controlled licensed **Unity 6 LTS** installation with Android Build
Support, create a **3D Built-In** project and copy this `Assets` folder into it.
Keep the project's own Editor-generated ProjectSettings/package versions.
Set Active Input Handling to legacy Input Manager or Both. Run
**EnergyBlast → Create pilot scene**, then Play, or
**EnergyBlast → Build Android debug APK**. No keyboard is required; UI and world
use touch/tap. Do not supply production signing keys for a development comparison.

`tools/sync_unity.py` supplies the same original robot source as FBX (Unity's native
import), the same common level/reward data generated as C# constants and the same
German audio files. Godot/GDevelop use the GLB exported from the same Blender
construction. Limb-node animation is procedural in all attempts, not imported
skeletal clips. This import-kit UI is less developed and has not been evaluated
for unreadable labels; do not use it as a validated child-facing alternative yet.
