# Original campaign arenas

These are deterministic original meshes generated by
`tools/make_defold14_worlds.py`. No external model, stock illustration or
reference-game asset was imported. The six original `defold09/floor-THEME.png`
illustrations are reused through explicit texture bindings; they are not copied
again into this folder.

Each of the sixteen missions has a semantic source mesh, an identical mesh
batched by material for runtime, and a floor ending at its exact arena bounds.
There is no outer space or scenery geometry. Solid armor details remain inside
their physical wall footprint. `surfaces.json` records the matching rectangles
and heights. The sheltered start has a physical room and a dogleg exit, separate
from the sanctuary's projectile-absorption rule.

Run `python3 tools/make_defold14_worlds.py` to regenerate geometry from current
rules, and `python3 tools/make_defold14_worlds.py --check` to verify actual vertex
buffers, source/runtime equality, collider bounds and hashes without regenerating.
The optional `--data` also rebuilds the full campaign rules from the frozen 0.13
baseline; do not use that option to preserve unrelated manual data edits.

`PROVENANCE.json` records the generator hash and individual geometry hashes.
These original project assets retain the repository's existing ownership terms.
